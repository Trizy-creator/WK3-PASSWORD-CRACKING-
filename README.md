 Week 3 – Password Cracking

Cybersecurity Practical Project week 3

 The main focus was learning about password cracking and understanding how weak passwords can be vulnerable to different cracking techniques.

 Tools Used

For this practical, I worked with:

1.John the Ripper (JtR) – Used to crack password hashes and test password strength.
2.NetworkWalks Password Cracking Tools – Used to practice password cracking techniques in a controlled environment.
3.PDF Hash Cracker – Used to work with password-protected PDF files and understand how their password hashes can be tested.

 What I Learned

Through this project, I learned:
* How John the Ripper can be used to crack hashes into passwords
* How PDF password protection can be tested using hash cracking techniques.
* Why strong and unique passwords are important for protecting accounts and files.

Technologies and Tools

John the Ripper (JtR) | NetworkWalks Tools | PDF Hash Cracker

 Ethical Use

All password cracking activities were performed for **educational purposes in a controlled environment**. Password cracking tools should only be used on accounts, files, or systems that you own or have explicit permission to test.
